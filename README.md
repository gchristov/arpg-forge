# Ashen Hollow

A small Diablo-style isometric action game for phones, in one HTML file. Walk a village at night, go into its buildings, and fight goblins and the dead down to the Bone Lord in the Old Crypt.

Everything is drawn in code on a canvas, so there are no images or other files to load.

## Play

Open `index.html` in a browser, on a phone or a desktop.

| Action | Touch | Keyboard |
| --- | --- | --- |
| Walk | Tap or hold the ground | |
| Attack | Tap an enemy, or the sword button | `2` or space |
| Fireball | Flame button (12 mana) | `3` |
| Potion | Flask button | `1` |
| Enter a building | Tap it, or walk into its door | |
| Talk | Tap a villager | |

## What's in it

- One village map with four buildings you can enter: the tavern (rest, buy potions), the smithy (make your sword stronger), a cottage with a chest, and the Old Crypt.
- Goblins, skeletons and skeleton archers that wander, chase and give up when you run far enough.
- The Bone Lord, who marks a circle before he slams it and calls up skeletons at half health.
- Levels, gold, potion drops, a quest arrow, and dynamic lighting.
